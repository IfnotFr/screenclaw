# Web Browser Expert Guide 🌐

## Core Principles
1. **URL Navigation**: Use the address bar to go to specific sites.
2. **Back navigation**: Always use `executeHotkey("alt+left")` to go back — never try to locate the back button visually.
3. **Focus**: Always ensure the browser is focused before starting any action. You can click on the toolbar to focus the browser.
